# Joystick Breakout — интерактивная игровая система на Arduino

Интерактивная игровая система, демонстрирующая интеграцию физического устройства ввода (аналогового джойстик-модуля) с виртуальной игровой средой. Аппаратная часть реализована на платформе **Arduino**, графическая часть — в среде **Processing 4**. В качестве игры реализован классический аркадный **Breakout**: платформа, управляемая джойстиком, отбивает мячик и разрушает кирпичи.

## About

Учебный проект, выполненный в рамках практики по курсу «Основы робототехники» 
(Московский Политех, направление «Управление в технических системах»).

## Описание проекта

**Цель:** создание интерактивной игровой системы, демонстрирующей интеграцию физического ввода (джойстик-модуля) с виртуальной игровой средой.

**Задачи:**
1. Нарисовать рабочую панель управления в Processing 4 (игровая платформа, мячик, кирпичи).
2. Организовать управление игровой средой при помощи аналогового джойстика.
3. Проверить работоспособность связки «джойстик → Arduino → Processing», оценить задержку и точность ввода.
4. При желании — расширить функциональность игровой среды.

**Ключевые слова:** контроллер, джойстик-модуль, игровая платформа, Arduino, Processing, интерактивный интерфейс.

Связь между платой Arduino и ПК осуществляется по последовательному порту (USB) на скорости 9600 бод: Arduino считывает аналоговые значения с осей X/Y джойстика и передаёт их в виде строки `Y,X,reset`, которую принимает и обрабатывает скетч Processing.

## Используемые компоненты

| Компонент | Кол-во | Назначение |
|---|---|---|
| Arduino UNO (или совместимый аналог, напр. Piranha Uno R3) | 1 | Центральный контроллер |

## Схема подключения

Поскольку модуль джойстика отсутствует в библиотеке Tinkercad, для симуляции в Tinkercad используется эквивалентная схема с двумя потенциометрами и двумя сервоприводами — она воспроизводит те же физические принципы обработки аналогового сигнала по осям X и Y.

## Установка и запуск

1. **Прошивка контроллера**
   - Откройте `arduino/joystick_controller/joystick_controller.ino` в Arduino IDE.
   - Подключите джойстик по схеме выше, выберите плату Arduino UNO и нужный COM-порт.
   - Загрузите скетч на плату.

2. **Запуск игры**
   - Откройте `processing/breakout_game/breakout_game.pde` в Processing 4.
   - Убедитесь, что Arduino подключена по USB (скетч автоматически использует первый доступный COM-порт — см. вывод в консоли Processing).
   - Запустите скетч (`Run`). При старте нажмите указанную клавишу/действие, чтобы начать игру.
   - Управляйте платформой, наклоняя джойстик по осям X/Y — задача разбить все кирпичи мячиком, не потеряв все жизни.
